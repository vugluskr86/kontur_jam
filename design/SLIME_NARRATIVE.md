# КОНТУР-041 — Slime / O-41 gameplay design

Версия: **0.6.0**

## Задача системы

Слизь должна пройти через четыре смысловые стадии:

```text
загрязнение → инструмент → собеседник → навигатор/соблазн
```

Если она остаётся только зелёной лужей с DOT-уроном, центральный сюжет об О-41 не проецируется на действия игрока.

## Типы взаимодействия

### Hazard slime

- повышает infection;
- замедляет;
- усиливает slime vignette/distortion;
- предупреждается визуально и шипением спор.

Функция: пространство, которое приходится обходить или проходить ценой ресурса.

### Symbiotic slime

- медленно снижает infection;
- не замедляет;
- визуально выглядит холоднее/спокойнее;
- может служить безопасной точкой рядом со сложной угрозой.

Функция: сломать однозначное правило «О-41 = яд».

### Resonance node

Interaction-volume `E`, который:

- помечает `slime:<id>`;
- увеличивает `slimeAttunement` только один раз;
- может дать heal;
- может добавить infection;
- запускает narrative beat;
- иногда меняет objective/route rule.

Повторный контакт idempotent.

## Level-specific функции

### Периметр

`perimeterEcho` передаёт образ ключа. Это первый намёк, что слизь хранит/передаёт информацию.

### Архив

`archiveConduit` синхронизируется с кабель-каналом. Если игрок принимает контакт, `archiveLoop` разрешается за два прохода вместо трёх.

### Реактор

`reactorVeil` временно убирает остаточный wail state. Сеть демонстрирует способность скрывать игрока от собственного резонансного хищника.

### Утроба

Три последовательно защищённых узла создают optional pilgrimage:

1. `wombCall1` — сеть просит идти по влажному следу;
2. `wombCall2` — спокойная слизь снижает стресс/infection и переводит фокус дальше;
3. `wombChoir` — фрагмент предупреждения оказывается совместим с частотой служебного канала `167.05`.

Узлы 2/3 нельзя «собрать задом наперёд»: guards требуют предыдущий контакт. Игрок всегда может отказаться и идти к обязательной сюжетной цели напрямую.

### Белое Безмолвие

Состояние предыдущих контактов определяет, какие финальные объекты материализуются после босса.

## Концовки как consequence graph

```text
                    ┌─ burn (always)
slimeAttunement ────┼─ merge (>=2)
                    ├─ broadcast (>=3 + evidence)
                    └─ sever (<=1 + evidence)
```

`evidence = archiveData && dossier`.

Это отделяет **доверие сети** от **знания правды о штабе**:

- можно глубоко довериться О-41, но не собрать доказательства;
- можно собрать доказательства и почти не контактировать с сетью;
- только сочетание обеих линий открывает передачу `167.05`.

## Визуальная связь

`SlimeSystem` отдаёт renderer две величины:

- `intensity` — близость к любой активной массе;
- `hazard` — интенсивность опасной массы.

`RetroRenderer` не рисует отдельный HUD meter. Вместо этого:

- края кадра получают характерный tint;
- появляется organic displacement;
- hazard смещает цвет в грязно-ржавый спектр;
- обычная vignette и infection остаются независимыми слоями.

## Audio связь

`slime:attuned` → `AudioSystem.slimeContact()`.

Внутренний сигнал не должен звучать как radio. Он routed через body + ambience, поэтому ощущается как событие внутри персонажа/пространства.

## Тесты

`test/slime.test.js` проверяет:

- idempotent attunement;
- hazard infection + slow;
- symbiotic infection reduction;
- ending availability по resonance/evidence.

`test/levels.test.js` проверяет наличие slime gameplay-zones на всех пяти уровнях и физическую достижимость финальных вариантов.
