# КОНТУР-041 — full FPS prototype

Three.js + Vite. Standalone-версии в проекте нет.

## Запуск

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## GitHub Pages

Сборка для Pages записывается в `docs/`; базовый адрес уже настроен для
репозитория `kontur041-fps-full`.

1. Создайте GitHub-репозиторий с именем `kontur041-fps-full` и загрузите в него проект.
2. В **Settings → Pages** выберите **Deploy from a branch**, ветку `main` и каталог `/docs`.
3. После изменений запускайте `npm run deploy` — команда соберёт игру, создаст коммит с `docs/` и отправит его на GitHub.

Игра будет доступна по адресу `https://<ваш-логин>.github.io/kontur041-fps-full/`.

Проверка логики и проходимости:

```bash
npm test
```

Отдельно:

```bash
npm run test:logic   # inventory/crafting/infection/progression contracts
npm run test:levels  # headless A* traversal по реальным collision boxes всех 5 уровней
```

## Управление

- `WASD` — движение
- мышь — обзор
- ЛКМ — огонь
- `E` — взаимодействие
- `1` / `2` — активный слот оружейного пояса
- `I` — пауза / инвентарь / крафт / назначение оружия в 2 слота
- `H` — использовать ингалятор
- `Q` — использовать мицелиевый щит
- `Space` — пропустить текущую реплику
- `R` — перезапуск после смерти

## Реализованный маршрут

1. **Периметр** — КПП, общежитие/столовая, Спороносцы, споры, ингалятор, ИЖ, пропуск смены и шлюз.
2. **Архив** — серверная, Плётчики, аудиозапись о «сигнале», грибной гранатомёт, АК, циклический неевклидов коридор.
3. **Реакторный блок** — туман 3–4 м, Вопленники, нарушенный компас/HUD, самозацикленная лестница, комната больше снаружи, Ядро-раздражитель, щит.
4. **Утроба** — органические пульсирующие стены, агрессивное заражение, Ходячие Ульи со спавном Спороносцев, ложная комната НИИ, личное дело Скальпеля, мицелиевый бур.
5. **Белое Безмолвие** — Резонатор, коллективный разум с тремя фазами и паттернами четырёх типов врагов, выбор «Сжечь / Слиться».

## Визуальный принцип

Референс Zero Tolerance используется структурно: небольшое читаемое 3D-окно окружено крупным непрозрачным HUD, радаром, оружейным поясом и статистикой. Палитра ограничивается при создании материалов и 64×64 Canvas-текстур, а не разрушительной пост-квантизацией готового кадра.

Post-process делает только low-res рендер, nearest-neighbor upscale, scanlines, шум и сюжетно обусловленные искажения от заражения/Вопленников/Ульев.


## Контракт переходов

Переход уровня больше не происходит непосредственно по нажатию `E`. Все четыре межуровневых перехода используют один физический контракт:

`обязательная цель → открыть шлюз → collider двери отключён → пройти за дверь → transition-trigger → следующий уровень`.

Обязательные флаги кампании:

- `perimeter → archive`: `shiftPass`;
- `archive → reactor`: `archiveData`;
- `reactor → womb`: `reactorCore`;
- `womb → silence`: `dossier`.

`ProgressionSystem` является единственным источником истины для этих prerequisites.

### Исправление Архива

На втором уровне серверная теперь физически закрыта. После чтения записи игрок трижды проходит пространственный цикл. Только третий проход открывает боковой шлюз серверной. После извлечения `archiveData` открывается отдельный шлюз реакторного блока; игрок должен физически пройти через него. Это устраняет прежний невидимый `E`-переход перед стеной.
